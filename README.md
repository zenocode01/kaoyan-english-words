# 考研英语一 · 真题词频背单词

一个离线网页应用，把两份资料融合成一个背词工具：

- 词书内容：来自「考研英语大纲词汇网页版」（6500+ 词条，含释义/词源/同义/搭配/例句）
- 词频数据：来自「考研英语真题词汇词频统计」（1980–2026 共 47 套英语一真题，变形词已归并）

原版词书「考研英语大纲词汇网页版」文件夹未做任何改动，保留作备份。

## 在线地址（手机推荐用这个）

**https://zenocode01.github.io/kaoyan-english-words/**

### 安装到手机（一次性）

- **安卓（Chrome/Edge）**：打开链接 → 菜单 → **安装应用 / 添加到主屏幕**（设置页内也有「立即安装」按钮）
- **iPhone/iPad（Safari）**：打开链接 → 分享按钮 → **添加到主屏幕**

安装后像普通 App 一样从桌面图标打开，**完全离线可用**（首次打开会自动缓存全部数据，约 1.4MB）。

### 关于学习记录

记录保存在各设备浏览器本地（localStorage），**手机和电脑之间不自动同步**：

- 换设备/换浏览器时用「设置 → 导出学习记录」备份，再在另一台设备「导入学习记录」
- iOS Safari 长期不用且清理了网站数据会丢记录，建议每周导出一次
- 请勿在 iPhone 上使用无痕模式访问

## 本地使用（电脑）

双击 `index.html` 即可（无需联网）。在线版更新后，手机打开会自动取新版本（缓存版本号递增后生效）。

## 功能（对标成熟软件，详见 竞品调研.md）

- **学习**：每日计划（默认 20 新词，按词频从高到低），间隔重复复习
  （1/2/4/7/15/30/60/120 天），三档自评：忘记 / 模糊 / 记得，快捷键 1/2/3、空格显示释义
  - 评分按钮预告下次复习时间（Anki 式）
  - 记忆强度条 0-100%（墨墨式）
  - 考试倒计时 + 建议每日新词量，可一键应用（墨墨目标倒推）
- **词表**：全库浏览 + 搜索，按词频/字母排序，按范围和状态筛选，复习中词条带强度条
- **测验**：英→中 / 中→英四选一 + 看释义拼写（首字母提示，仿扇贝首字母填空），错题自动进错题本，答对后移出
- **统计**：进度、待复习量、连续天数、词频分层 × 掌握程度、学习日历热力图（Duolingo 式）
- **设置**：每日新词量 / 背诵范围 / 新词顺序 / 考试日期 / 日夜主题 / 进度导出导入

卡片右上角朱砂印章 = 词频等级：极高(≥100) / 高频(≥30) / 常考(≥8) / 罕见(≥1) / 未出现。

## 背诵范围说明

计划只纳入在 47 年真题中实际出现过的词（f>0）：
仅必考词 ≈ 1500 词 → 必考+基础 ≈ 3400 词 → 全部 ≈ 5200 词。
建议顺序：极高 56 词 → 高频 399 词 → 常考 1014 词，这三层就是应试核心。

## 数据重建

词书或词频更新后，在本文件夹执行：

```
node build/合并词书数据.js
```

会重新生成 `vocab-data.js`（词书 + 词频合并结果，词书缺失的大纲高频词自动补充）。
